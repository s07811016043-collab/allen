    如何获取视频链接与 decode_key

    视频号视频是加密的，需要「视频直链」和「decode_key」两样东西才能解密。以下是不用装证书的通用方法：

    1. 用电脑浏览器打开 https://channels.weixin.qq.com/，登录后找到目标视频；或在微信中「复制链接」后用浏览器打开。
    2. 按 F12 打开开发者工具，切到 Network（网络） 面板，勾选保留日志。
    3. 播放该视频，在请求列表里筛选 finderGetCommentDetail 或包含 object_desc 的接口。
    4. 在返回 JSON 里找到 media[0].url（视频直链）和 media[0].decode_key（数字）。
    5. 把整段 JSON 粘贴到「智能下载」的输入框，点识别后开始下载；或手动填入两个字段。
    也可以先用浏览器直接把视频直链下载成 .mp4（此时是加密的、只能播放前几秒）， 再到「本地解密」页选它 + 填 decode_key 得到可正常播放的视频。

    解密原理

    微信视频号只加密文件前 128KB（131072 字节），其余为明文。加密使用以 decode_key 为种子的 ISAAC-64 伪随机数生成器产生 128KB 密钥流，再对文件头部逐字节 XOR。本工具用同样算法生成密钥流并再做一次 XOR 即可还原。核心算法为纯 JavaScript 实现，已与公开的 Go 参考实现逐字节比对一致。
