## 1. 第一轮（提示词 v1.0）——不一致 ✗

选题规则只有「重要性 + 时效」两维打分，产出的重点新闻为：

> 备案 ×2、支付宝×OPPO、京东×元宝、OpenAI 音箱、**三星 Q3 DRAM 提价 20%**、**SK 海力士重启 NAND 厂**、GPT-5.6 Sol（8 条）

**偏差：** 目标第 6 条是「存储涨价传导到手机」这条*主线*，而 v1.0 把上游两条厂商动态
（三星提价、海力士建厂）各自单列，挤占了重点位。

**修改：** 加入分栏规则 3、4 ——「同一主题只保留一条主新闻」「供应链价格类必须以
向终端/BOM 传导的形态呈现」；单一厂商产能/报价动态降级为补充新闻。

## 2. 第二轮（提示词 v1.1）——重点一致，精选不一致 ✗

重点 7 条已与目标完全一致。但精选文章产出为：

> ①三万条聊天记录 ②AI Coding 工具链 ③**《封了自家元宝，微信 AI 亲自下场》（钛媒体）**

**偏差：** 目标第 3 篇是《英伟达正在完成「五层蛋糕」闭环》。v1.1 只按「深度 + 热度」选文，
第 3 篇与当日重点（京东×元宝）主题重叠，且三篇全部集中在应用层。

**修改：** 加入精选规则——三篇须覆盖「应用与用户层 / 工程与工具层 / 算力与产业层」
三个不同层面，且不得与当日重点新闻主题重复。修改后：应用层=聊天记录（呼应 Agent 主线）、
工程层=AI Coding 工具链、产业层=英伟达五层蛋糕。

1. 按《日报生成提示词.md》第二节清单采集当日信息源 →
2. 将候选池 + 提示词全文喂给模型，产出结构化内容 →
3. 将内容 + 《日报样式提示词.md》喂给模型，产出单文件 HTML →
4. 按第六节自检清单校验后发布。
