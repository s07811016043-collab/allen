# AI 情报晨报 · 格式与样式提示词（反推版 v1.1）

> 依据 3 张真实日报截图反推的视觉规范。与《日报生成提示词.md》配合使用：
> 内容提示词产出结构化内容，本提示词负责渲染成单文件 HTML（自适应亮/暗两套主题，
> 对应截图中的浅米色版与深色版）。

---

## 一、渲染指令（System）

```
把日报内容渲染成一个自包含的单文件 HTML（内联全部 CSS，不引用任何外部资源）。
整体气质：情报简报 / 晨报排版——纸感底色、衬线标题、编号徽章、批注式点评块。
移动端优先：单栏、最大宽度 720px 居中，所有宽内容可横向滚动，页面本身不横滚。
同时支持亮色（默认，米色纸感）与暗色（prefers-color-scheme: dark）两套主题。
```

## 二、设计规格（Design Tokens）

| Token | 亮色 | 暗色 |
|---|---|---|
| 页面底色 `--bg` | `#f4efe4`（米色纸感） | `#17181c` |
| 卡片底色 `--card` | `#fbf8f0` | `#1f2127` |
| 正文色 `--ink` | `#2b2a26` | `#d8d5cc` |
| 次要文字 `--muted` | `#8a8578` | `#8b8878` |
| 强调红（徽章/标题装饰）`--accent` | `#c0392b` | `#e05d4a` |
| 点评块底色 `--note-bg` | `#f0ead2`（浅橄榄黄） | `#2a2a20` |
| 点评块左边线 `--note-line` | `#a68a2d` | `#c9ad4b` |
| 分隔线 `--line` | `#e2dbc8` | `#33353c` |
| 链接色 | `#8c6d1f` | `#c9ad4b` |

**字体：**
- 标题：衬线 `"Noto Serif SC", "Songti SC", serif`，加粗。
- 正文：无衬线 `"PingFang SC", "Noto Sans SC", sans-serif`，15px/1.75。
- 数字徽章、日期：等宽或半衬线均可，字重 700。

## 三、版块结构与样式细则（自上而下）

1. **页眉**
   - 大标题「AI 情报晨报」：衬线、28–32px、居中或左对齐，下方一条 2px 强调红短线。
   - 日期徽章：红底（`--accent`）白字圆角胶囊，如 `2026-07-16`。
   - 副标题一行小字（`--muted`）：`信息窗口 07-15 08:00 — 07-16 08:00 · 扫描 34 个每日必扫信息源 · 重点 7 条 / 补充 5 条`。

2. **今日重点新闻**
   - 版块标题：衬线加粗 + 左侧 4px 红色竖条。
   - 每条新闻是一张卡片（`--card` 底、1px `--line` 边、12px 圆角、内边距 16–20px），卡片间距 14px。
   - **序号徽章**：22px 圆形、红底白字、加粗数字，悬挂在标题左侧。
   - 标题：16–17px 加粗；正文 15px。
   - **点评块**：`--note-bg` 底 + 3px `--note-line` 左边线 + 8px 圆角；
     以加粗「点评：」开头（截图中亮色版为「点评」、深色版同构）。
   - **来源行**：13px `--muted`，格式 `来源：媒体名`，媒体名带链接下划线；多源以「 / 」分隔。

3. **补充新闻**
   - 同卡片体，但更紧凑：无点评块，标题 15px，正文 1–2 句 14px，来源行同上。
   - 序号徽章改为描边空心圆（红边白底红字），与重点新闻区分层级。

4. **对我们的意义**
   - 整个版块是一张大卡片，左侧 4px 强调红竖条。
   - 每条前置标签胶囊：`机会`（绿底 `#3d7a44`/白字）、`风险`（红底）、`建议`（黄底 `#a68a2d`/白字）。

5. **今日 AI 精选**
   - 每篇：衬线加粗标题（带链接）+ 一句「为什么值得读」（`--muted`）。

6. **今日一句总结**
   - 反色大卡片：亮色主题下用深色底（`#2b2a26`）浅字；暗色主题下用更深底 + 描边。
   - 首行小标「今日一句总结」，正文 15px/1.9，主线短语用引号并以强调色标出。

7. **主要来源（页脚）**
   - 12px `--muted`，来源名以「 · 」串联；末行版权/免责一句：
     `内容由 AI 自动聚合生成，仅供内部参考，请以原文为准。`

## 五、渲染自检

- [ ] 亮/暗两套主题都完整可读（点评块、总结卡、徽章在两套下均有对比度）？
- [ ] 无任何外部请求（字体/图片/JS 全内联或系统字体回退）？
- [ ] 手机宽度（375px）不出现横向滚动？
- [ ] 序号徽章样式区分了重点（实心）与补充（空心）？
- [ ] 所有链接可点击且为原文 URL？
