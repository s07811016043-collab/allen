# 调研平台前端(C 端原型)

基于 `research-platform-prd.md`(V1.2)实现的用户端网页原型:Vite + React + TypeScript,无后端依赖,数据为 mock(打分/积分持久化在 localStorage)。

## 运行

```bash
cd web
npm install
npm run dev      # 开发,默认 http://localhost:5173
npm run build    # 构建到 dist/
npm run preview  # 预览构建产物
```

## 已实现(对应 PRD 章节)

| 模块 | PRD | 说明 |
| --- | --- | --- |
| 邀请码 + 简单登录 | 5.3 / 5.4 | 邀请码校验(mock 码见 `src/mock.ts` 的 `VALID_INVITE_CODES`,如 `EVAL2026`)、Google 一键登录(mock)、邮箱验证码(mock,任意 6 位)、协议勾选 |
| 多语言四语全覆盖 | 5.9 | EN/FR/DE/JA 全量文案;默认语言按地区自动判定(原型以浏览器语言代替 IP 定位),手动切换后偏好优先并持久化 |
| 任务大厅 | 5.2 | 三类算法任务卡片、进度、防分享提示 |
| 高光时刻打分 | 5.5.2 | 原始素材组 + 模型选中结果(带排序)、5 维李克特打分、"更应入选"点选、视频播放 ≥50% 才可提交 |
| 美学评分打分 | 5.5.3 | 大图展示(不展示模型分)、5 维打分 |
| 关键词搜索打分 | 5.5.4 | 关键词按用户语言展示、结果图带排序、逐图三档相关性标记、5 维打分 |
| 通用打分交互 | 5.5.1 | 分值锚点、必填校验、跳过原因弹窗、作答时长记录、可选文字反馈(200 字) |
| 积分与兑换 | 5.8 | 有效打分 +10、兑换页(库存/积分门槛/申请状态)、兑换记录 |
| 个人中心 | 5.3.2 | 打分统计、语言设置、退出、注销(GDPR mock) |
| 防扩散(前端约束) | 5.4.2 | 素材水印(用户哈希)、禁右键/长按保存、防分享提示 |

## 结构

```
web/src/
  i18n.ts        # 四语词典 + 语言检测
  mock.ts        # 中台推送数据的 mock(结构对齐 PRD 5.1.2)
  store.tsx      # 全局状态:用户/语言/打分/积分,localStorage 持久化
  components.tsx # 李克特、媒体瓦片(水印/视频进度)、导航等
  pages/         # Login / Home / 三类打分页 / Rewards / Profile
```
