# 度量台桌面版（eval-app）

把 `eval-dashboard/` 网页打包成**双击即用的桌面应用**：打开后自动在本机启动内置 Web 服务（仅监听 `127.0.0.1`）并自动弹出默认浏览器。

## 技术方案与选择理由

| 方案 | 结论 |
|---|---|
| **Go 单文件可执行程序（采用）** | 静态资源经 `go:embed` 编译内嵌，产物 ~7MB、零运行时依赖、一条命令交叉编译出 Win/macOS/Linux 三平台，天然贴合"离线、轻部署"的 NAS 团队场景 |
| Electron / Tauri（未采用） | 度量台无需系统级 API（托盘/文件系统深度集成），为一个静态页背 150MB+ 运行时或 Rust 工具链不划算；浏览器本身就是最好的 UI 宿主 |

## 直接下载使用

`dist/` 目录（或 GitHub 分支页面下载）：

- `度量台-Windows.zip` — Windows 10/11（exe 已内嵌应用图标、产品版本信息与清单）
- `度量台-macOS-Apple芯片.zip` — macOS M1/M2/M3/M4（标准 .app 包，含图标；附「首次打开前双击我-移除隔离.command」一键信任脚本）

双击运行 → 自动启动本机服务并打开浏览器。系统安全提示的处理见压缩包内 `使用说明.txt`。

**关于信任**：未购买商业代码签名证书（Apple Developer ID / Windows Authenticode）时，系统首次打开会有一次性提示，属正常现象。已做的无证书信任措施：macOS 侧 Go 工具链自动附加临时（ad-hoc）签名 + 标准 .app 包 + 一键移除隔离脚本；Windows 侧注入产品名/版本/公司元数据与应用清单。要彻底消除提示需企业采购证书后签名/公证（一次性工作）。

## 从源码构建

```bash
# 依赖：Go 1.21+；网页源在 ../eval-dashboard/
./build.sh   # 同步网页资源到 web/ 并交叉编译到 dist/
```

网页功能改动只需改 `eval-dashboard/`，重新跑 `build.sh` 即可；`web/` 是构建时的快照，不要直接编辑。

## 行为细节

- 端口：依次尝试 8471/8472/8473，全占用则随机端口（地址以启动窗口打印为准）
- 安全：拒绝非 `127.0.0.1` 来源的请求；无任何外部网络调用；评测数据仅在浏览器内计算
- 停止：关闭终端窗口或 Ctrl+C
