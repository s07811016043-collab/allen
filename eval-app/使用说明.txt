搜索与文案生成效果度量台 · 桌面版使用说明（v1.1）
====================================================

一、打开方式
  ● Windows：双击「度量台.exe」
  ● macOS（Apple 芯片 M1/M2/M3/M4）：
      第 1 次使用：先双击「首次打开前双击我-移除隔离.command」
      （若它本身也被系统拦下：对它按住 Control 点击 → 打开 → 再点"打开"）
      之后：直接双击「度量台.app」即可

  打开后程序会自动：
  1. 在本机启动服务（首选端口 8471，被占用自动换）
  2. 打开默认浏览器进入度量台页面
  3. 关闭程序窗口（Windows 的黑色窗口 / macOS 的终端窗口）= 停止服务

二、系统信任说明（为什么会有安全提示）
  本程序未购买商业代码签名证书（Apple Developer ID / Windows Authenticode），
  属于企业内部工具的正常情况，程序本身不联网、无任何风险行为。

  ● Windows SmartScreen 提示"已保护你的电脑"：
      点「更多信息」→「仍要运行」。程序属性中可看到产品名/版本/公司信息。
      如需彻底消除提示，需为公司申请代码签名证书后重新签名（一次性采购项）。

  ● macOS 提示"无法打开，因为无法验证开发者"：
      方式 A（推荐）：双击附带的「首次打开前双击我-移除隔离.command」一键处理；
      方式 B：按住 Control 点击 度量台.app → 打开 → 再点"打开"（只需一次）；
      方式 C：系统设置 → 隐私与安全性 → 底部点"仍要打开"。
      如需彻底消除提示，需加入 Apple Developer Program 做签名+公证（一次性采购项）。

  ● macOS 首次启动可能询问"「度量台」想控制「终端」"：点「好」。
      这是启动器在终端里为你展示服务地址与日志所需的一次性授权。

三、安全设计
  · 服务只监听 127.0.0.1（仅本机可访问，局域网内其他设备会被拒绝）
  · 网页资源全部内嵌在程序内，运行全程不发起任何外部网络请求
  · 上传的评测数据只在你的浏览器里计算，不落盘、不上传

四、怎么用
  页面内「操作步骤」页签有完整流程：
  · 推荐先在对应页签下载 Excel 模板（含填写说明与示例行），填好后整个文件拖入上传区
  · 也可上传任意列名的 Excel/CSV，系统自动识别关键信息；缺什么、怎么补，页面会提示
  · 每个页签的「用示例数据看效果」可先看演示
