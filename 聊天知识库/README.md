> 一套基于心理学实证研究 + 实战经验整理的聊天方法论与案例知识库。
> 核心立场：真诚、尊重、对等。技巧只是"让真诚被看见"的手段，不含任何 PUA/打压/操控内容。

## 快速上手路径

1. **先读报告**：掌握五阶段模型（破冰→熟悉→升温→深化）和八大方法，尤其是"追问式倾听"和"相互自我表露"两个被研究验证的核心机制。
2. **按需查库**：
   - 不知道怎么开口 → `01-开场白案例库`
   - 没话题了 → `02-话题库`
   - 她发了消息不知道怎么回 → `03-高情商回复惯例`
   - 想看完整对话怎么打的 → `04-实战案例分析`
   - 想约她出来 → `06-邀约与推进案例`
3. **每周复盘**：对照 `05-常见错误与雷区案例` 末尾的自检清单，检查自己最近的聊天记录。

## 三条最重要的原则（全库浓缩）

1. **追问 > 找新话题**：对她刚说的话问一个走心的追问（哈佛研究：追问显著提升好感与二次约会率）。
2. **一问一答一分享**：每问她一个问题，附上自己的答案；表露深度逐步升级（Aron 36 问研究）。
3. **投入度对等**：你的主动只比她高半档；红灯信号出现时降速止损，而不是加码感动自己。
